# Manifesto de importação pt-PT · versão 1

Este manifesto fixa as cópias Markdown do dicionário português europeu Hunspell;
não é um catálogo de comandos. O código Python valida o conteúdo de cada
ficheiro por hash de objeto Git SHA-1, com o hash deste manifesto selado no
Front Door. O índice SQLite FTS5 é reconstruído em memória.

Origem: https://github.com/streetsidesoftware/cspell-dicts/tree/main/dictionaries/pt_PT/src/hunspell
